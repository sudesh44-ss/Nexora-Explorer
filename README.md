# 🚀 Nexora Explorer

**Nexora Explorer** is a modern, powerful, and feature-rich Windows File Explorer designed to provide a faster, cleaner, and more advanced file management experience. 🗂️💻

## ✨ Features

- 🏠 **Modern Home Interface**
  - Quick Access
  - Favorites
  - Recent locations
  - Devices & Drives

- 💽 **Drive Management**
  - Browse all available drives
  - View Total Capacity
  - View Free Space
  - Grid, List, and Details views

- 📁 **File & Folder Management**
  - Browse files and folders
  - Create and manage folders
  - File and folder navigation
  - Native Windows folder selection

- 🔍 **Advanced Search**
  - Filename search
  - Recursive/Subfolder search
  - File type filtering
  - Extension filtering
  - Size filtering
  - Date filtering
  - Boolean operators such as `AND`, `OR`, and `NOT`
  - Regex search
  - Search cancellation
  - Search history
  - Saved searches

- 🎨 **Flexible Views**
  - Grid View
  - List View
  - Details View
  - Adjustable item size
  - `Ctrl + Mouse Wheel` support

- 🖱️ **Mouse Interaction**
  - Configurable Single Click / Double Click behavior
  - Adjustable item sizing
  - Smooth navigation

- ⚙️ **Settings & Preferences**
  - Persistent application settings
  - View preferences
  - Click behavior preferences

- 📊 **Storage Information**
  - Total disk capacity
  - Free disk space
  - Drive information across available drives

- 🔄 **Navigation**
  - Back / Forward navigation
  - Navigation history
  - Home startup interface

## 🛠️ Technology

## 🔎 Advanced Search Examples

```text
name:photo
````

Search files by name.

```text
type:image
```

Search image files.

```text
size:>100MB
```

Find files larger than 100 MB.

```text
type:image AND size:>50MB
```

Find images larger than 50 MB.

```text
name:invoice
```

Find files containing "invoice" in their name.
